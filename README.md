# Tevin's BSIS – Book Shop Inventory System

A simple, responsive web app for book shops to manage inventory. Built with HTML, CSS, and JavaScript (vanilla, no frameworks).

## Features
- Dashboard with quick stats
- Add, view, search, and delete book supplies
- Book details: title, author, quantity, price (KES), category
- Real-time search + custom toast notifications
- Dark/light mode toggle (saved in browser)
- Mobile-friendly sidebar menu
- Data persists using localStorage

## How to Run
1. Clone or download this repository
2. Open `index.html` in any web browser (Chrome, Edge, Firefox)

No server or installation required!

## Technologies
- HTML5
- CSS3 (responsive + dark mode)
- JavaScript (form handling, DOM, localStorage)
- Font Awesome icons
